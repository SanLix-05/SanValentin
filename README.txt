# 🌹 Para una geóloga increíble

Una página web romántica e interactiva hecha con HTML, CSS y JavaScript.

## Cómo abrirla

1. Descarga/descomprime la carpeta.
2. Abre `index.html` con Google Chrome, Edge o Firefox.
3. No necesita servidor: funciona directamente en el navegador.

## Archivos

- `index.html` → estructura y contenido.
- `style.css` → diseño, animaciones y responsive.
- `script.js` → preguntas, respuestas, lluvia de rosas y navegación.

## Personalización rápida

Puedes cambiar:
- Las preguntas de geología en `index.html`.
- El mensaje final en `index.html`.
- Colores, tipografías y estilos en `style.css`.
- La cantidad de rosas en `script.js` modificando `55`.
